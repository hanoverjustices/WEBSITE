HJPA WEBSITE UPDATE — 11 September 2026

UPLOAD
1. Extract this ZIP.
2. In the existing GitHub repository choose Add file > Upload files.
3. Upload index.html, CNAME and the entire assets folder, then commit changes.
The CNAME contains hanoverjpa.com. Keep that domain setting.

Announcements & Events added below homepage ribbon with three original flyers, date filters, full-size viewing, zoom, download and Gia event answers. The homepage Ask Gia button now links to events; the floating assistant remains.
Custos portrait replaced with the cleaner image selected by the user.
Become a JP now has direct internal navigation and English-literacy guidance.
JP Annual Report has navigation, a homepage card, the official Microsoft form, an optional in-page form and a printable-form link.
Known-unavailable Ministry PDFs show an explanation with a retry link instead of a broken embedded preview. Other resource viewers retain a direct-open fallback.
Gia can direct visitors to annual reporting. Existing image data and leadership content are preserved.

JavaScript syntax and targeted interaction logic checks passed. Original embedded image data matches the previous ZIP.

Ministry webpage and both PDF links returned HTTP 502. No official PDFs could be downloaded or bundled; the printable and application links still depend on the Ministry service becoming available.

This package does not itself publish the update. Upload it to the existing GitHub repository.
