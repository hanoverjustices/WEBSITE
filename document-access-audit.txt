# HJPA document-access audit — 23 September 2026

## Result

The live website and repository served the same earlier Gia HTML. This update includes the v15 reviewed training answers and the document-access repairs. It has not been committed or deployed to GitHub by this task.

Seven resource entries now use supplied local PDFs: JP Act, 2021 amendment (within the Act compilation), JP Jurisdiction Act, Official Seals Regulations, Bail Act 2023, JP Training Manual, and the annual-report Second Schedule (within the Act, PDF page 24).

All 14 original training/legal PDFs are included byte-for-byte. The main resource centre and Gia share a catalogue embedded in index.html. The standalone document-catalogue.json is an inspection copy; editing it alone does not rebuild Gia or change the site. Publication dates are shown only when known. Copies are not represented as independently confirmed current law.

## Live access results

- 45 unique resource/MOJ URLs checked using HTTP GET with certificate verification enabled. Ten Google Drive viewer/preview pages returned HTML with HTTP 200; that does not establish that the underlying PDF renders. No external PDF bytes were retrieved.
- All 35 MOJ/laws.moj requests failed from this environment. Exact errors are retained in link-audit.json. These are environment observations, not a claim that the Ministry is universally offline. Browser embedding restrictions and certificate failures were not established as the cause.
- The existing annual-report Microsoft Forms short link returned HTTP 200 and redirected to the expected response page. The embedded-form request timed out. No form was submitted and end-to-end submission was not tested. The official endpoint remains external.
- The current repository build script and workflow were retrieved successfully. Existing push-on-main deployment is retained; no workflow edits or manual run are required for this update.

## Important document distinction

The old Official Seals Act is NOT the supplied Official Seals Regulations. The supplied JP Act, section 24, PDF page 20, records repeal of the former and saving of the latter. The resource title now identifies the Act as historical/repealed, retains its original official URL, and separately offers the local repeal provision and Regulations. No Regulations PDF was substituted under an Act title.
